# Prototype Versus Production

| Area | Submitted prototype | Production target |
|---|---|---|
| Business inputs | Browser-entered values or disclosed synthetic demo | Consent-based integrations and governed user entry |
| Financial analysis | Deterministic calculations and prototype ranges | Same deterministic core with governed reference datasets |
| Policy knowledge | Included official snapshots in SQLite | Scheduled collection, review, versioning, and freshness operations |
| Eligibility | Conservative `CHECK_REQUIRED` where uncertain | Human/agency confirmation with auditable workflow |
| Specialist outputs | Deterministic trusted templates | Enterprise internal local LLM proposals behind the same contracts and verifiers |
| Market/store/vacancy | `PLANNED_INTEGRATION` | Provenance-complete approved provider feeds |
| Consultation | Consent preview only; no live transmission | Authenticated, logged, consented advisor workflow |
| Security/operations | Local demonstration controls | Enterprise IAM, encryption, retention, monitoring, recovery, and governance |

The model gateway deliberately names no required vendor or model. Model selection needs a separate enterprise evaluation for Korean accuracy, structured-output reliability, latency, hardware capacity, licensing, privacy, and security. This submission reports no local-model benchmark.

## Factual boundaries

- Prototype values are user-entered or synthetic; the Croatian restaurant is an optional synthetic demo.
- Industry ranges are `PROTOTYPE_REFERENCE_RANGE`, not official averages.
- Policy data is made from versioned official-source snapshots and unresolved eligibility is `CHECK_REQUIRED`.
- ChatGPT aided the prototype agent-result design; deterministic trusted templates run in the current prototype.
- The production target is an enterprise internal local LLM behind the model-independent gateway.
- No local model was installed, run, or evaluated for this prototype.
- Market, nearby-store, and vacancy feeds remain `PLANNED_INTEGRATION` until approved providers exist.
